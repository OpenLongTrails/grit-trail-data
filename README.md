# grit-trail-data

This repo contains the trail data used in the thruhiking app OpenLongTrails Grit.

## Layout

A trail directory typically contains:

- `tracks.geojson`: the trail itself
- `milepoints.geojson`: distances along the trail
- `waypoints.geojson`: points of interest along the trail, eg campsites, water 
  sources, road crossings, etc.

## Schema

Note that the schemas for these files are not finalized and remain subject to change.
